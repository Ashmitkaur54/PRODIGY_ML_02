# Customer Segmentation using K-Means Clustering

This project was completed as part of my Machine Learning Internship.

## Objective
Apply the K-Means clustering algorithm to segment customers based on their annual income and spending score.

## Dataset
Mall Customers Dataset

**Dataset Link:**
https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Workflow
- Import Dataset
- Data Preprocessing
- Feature Selection
- Finding Optimal Clusters (Elbow Method)
- K-Means Clustering
- Cluster Visualization

## Results
- Successfully segmented customers into different groups using K-Means Clustering.
- Visualized customer segments to analyze purchasing behavior.
